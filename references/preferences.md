# Reusable editing preferences

Defaults derived from the commissioning editor's brief, always superseded by current instructions:
- Preserve the user's organized project and manual edits.
- For vertical social reels, 2160 x 3840 at 30 fps is a useful starting default; verify the target before creating a timeline.
- Explain the story through a small number of meaningful beats. Keep customer statements in context; intercut by idea rather than mechanically completing each speaker's interview.
- For energetic product reels, prefer purposeful action, sound and varied pacing over constant fast cuts or decorative transitions.
- When all takes are requested, provide all relevant accessible full-length sources and alternate angles. A later final cut can be selective.
- If story approval is requested, present the concrete story/cut before additional finishing changes. If versions must stay in one timeline, separate them with explicit gaps and markers. Do not assume those constraints apply to every new project.
- Concise progress and honest completion evidence matter more than repeated assurances.

Client names, private paths, transcripts, live project counts and prior timeline IDs are intentionally omitted. Obtain current project facts from the user's session or authorized local records.
